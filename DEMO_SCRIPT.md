# Sprint Doctor — demo video script (under 5 min, target ~2:30)

Record on the real dev Jira site after `forge deploy` + `forge install`.
No narration over copyrighted music; screen recording + voiceover (or
captions). Keep every claim tied to something visible on screen.

## 0:00–0:20 — The problem

Show a Jira sprint board with a few visibly stale/blocked issues.
Voiceover: "Every sprint quietly rots — blocked issues nobody notices,
tickets untouched for two weeks, one person carrying half the sprint.
Teams find out in the retro, too late."

## 0:20–1:10 — The project page (sprint triage board)

Open the Sprint Doctor project tab. Point at: sprint health score,
blocked / stale / at-risk counts, the overloaded assignee line, and
the "needs attention" table sorted worst-first. Open one at-risk
issue's row and read its top finding aloud.

## 1:10–1:45 — The issue panel

Open the worst issue. Show the Sprint Doctor panel: score, level,
each finding with its suggested next step. Voiceover: "Every finding
comes with the fix — not just a red number."

## 1:45–2:20 — The Rovo agent

Switch to Rovo chat. Ask: "What's blocking this sprint?" Show the
agent answering with issue keys and blocking keys from the same data.
Then: "Post the triage summary on SD-102?" — show the agent asking
for confirmation first, then (after confirming on camera) the comment
appearing on the issue. Voiceover: "It never writes without asking."

## 2:20–2:30 — Close

Back to the board. Voiceover: "Sprint Doctor — a Forge app for Jira.
Built for Codegeist 2026. Free to install from the link below."
End card: installation link + GitHub repo link.

## Recording checklist

- [ ] Dev Jira site with a sprint containing at least one blocked, one
      stale, and one overloaded-assignee issue (fixture-style data is
      fine on a dev site — say so on camera if asked, but the demo
      itself runs on live Jira data from that site).
- [ ] Rovo enabled on the dev site (Standard/Premium trial).
- [ ] Captions on (accessibility + judges watch muted).
- [ ] Upload to YouTube as Public (unlisted is NOT enough — the rules
      require publicly visible), paste the link into the Devpost form.
